Dos tipografías bastan: cómo combinarlas en una web

Una para los títulos y otra para el texto. Reglas simples para que la página se lea con comodidad.

Tipografía   Publicado el 9 de octubre de 2026

No necesitas muchas fuentes para que una página se vea profesional. Con dos bien elegidas y un orden claro, el texto se lee mejor y la marca se reconoce.

Una para títulos, otra para texto

Elijo una tipografía con personalidad para los títulos y otra más neutra para los párrafos. Deben verse distintas: dos fuentes casi iguales parecen un error. En este blog uso Sora para los títulos y Newsreader para leer.

Crea una jerarquía

Los tamaños comunican el orden de importancia. Fijo una escala sencilla —por ejemplo, cada nivel un 25 % mayor que el anterior— y la repito en todas las páginas.

Cuida la lectura

  • Interlineado de alrededor de 1,5 veces el tamaño en los párrafos.
  • Líneas de entre 45 y 75 caracteres.
  • Pocos pesos distintos: normal, seminegrita y negrita bastan.

Carga las fuentes con cuidado

Al usar Google Fonts conviene pedir solo los pesos que se usan, añadir display=swap y definir una fuente de respaldo para que el texto aparezca aunque la fuente tarde en cargar.

Resumen

Dos familias, una escala de tamaños, buen interlineado y líneas de longitud cómoda.
